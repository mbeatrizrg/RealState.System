# Punto 3 — Metodología de negocio

> Parte de la defensa del CRM de Rifat Richani Bienes Raíces. Puntos: [1. Por qué lo hicimos](01-por-que-lo-hicimos.md) · [2. Tecnologías](02-tecnologias.md) · **3. Metodología de negocio** · [4. Cómo funciona](04-como-funciona.md)

## Inbound + embudo de ventas

El proyecto sigue la metodología **inbound**: el cliente llega **por su cuenta**, atraído por el portal, en lugar de que el vendedor lo busque en frío (outbound). El sistema cubre las cuatro fases del ciclo:

| Fase | Dónde ocurre | Qué pasa |
| --- | --- | --- |
| **1. Atraer** | Portal | Catálogo, búsqueda por filtros, fotos, características y mapa |
| **2. Convertir** | Registro / consulta | El visitante se registra (código al correo) o pide información: nace un **contacto** y un **lead** |
| **3. Cerrar** | Negocios, tareas, actividades | El negocio avanza por etapas con visitas, ofertas y trámites |
| **4. Medir** | Estadísticas | Qué atrae, qué convierte y quién cierra |

## El embudo: 7 etapas de cada negocio

Un **negocio** es una oportunidad concreta: un cliente interesado en un inmueble, para venta o alquiler.

```
Prospecto → Cita/visita programada → Visita realizada → Oferta/negociación → Trámites legales → Cierre ganado
                                                                                              ↘ Cierre perdido
```

| Etapa | Significa |
| --- | --- |
| Prospecto | El cliente mostró interés en el inmueble |
| Cita / visita programada | Se agendó una visita |
| Visita realizada | El cliente conoció el inmueble en persona |
| Oferta / negociación | Hay una oferta o se negocia el precio |
| Trámites legales | Se prepara el contrato y los documentos |
| Cierre ganado | Se vendió o se alquiló |
| Cierre perdido | El cliente desistió |

En el CRM estas etapas se ven como un **tablero (pipeline)**: cada etapa es una columna con el **monto total** de sus negocios, y las tarjetas se arrastran de una a otra.

## Principios que aplica el sistema

| Principio | Cómo se ve en el CRM |
| --- | --- |
| **Un responsable** | Cada contacto, negocio y tarea tiene un vendedor propietario; existen las pestañas «Mis…» y «Sin asignar» |
| **Todo queda escrito** | Notas, correos, llamadas, reuniones, tareas y cambios de etapa forman el historial del cliente |
| **Se mide** | Monto por etapa, tasa de cierre, comportamiento del cliente frente a cada inmueble y rendimiento por vendedor |

## Cómo se mide el comportamiento del cliente

En Estadísticas, cada par **cliente-inmueble** se clasifica según hasta dónde llegó:

`Solo pidió información → Agendó visita → Realizó visita física → Presentó oferta → Compró / alquiló` (o **Descartó**)

Así la inmobiliaria sabe, por ejemplo, cuántos interesados llegan a visitar y cuántos de esos ofertan.

## Para estudiar

**Lo que hay que saber decir (en 30 segundos):**
1. La metodología es **inbound**: el portal atrae al cliente y el CRM lo convierte y lo acompaña.
2. Las cuatro fases: atraer, convertir, cerrar y medir.
3. Cada oportunidad es un negocio que pasa por **7 etapas**, con un **responsable**, un **historial** y **métricas**.

**Conceptos que hay que poder explicar:**

| Término | Explicación simple |
| --- | --- |
| **Inbound** | El cliente te encuentra a ti (por el portal) en vez de que tú lo busques. |
| **Lead** | Un interesado que pidió información de un inmueble. |
| **Contacto** | Una persona registrada con la que la inmobiliaria tiene o puede tener relación comercial. |
| **Negocio (oportunidad)** | Un contacto + un inmueble + una operación (venta o alquiler) que avanza por etapas. |
| **Embudo / pipeline** | Las etapas por las que pasa un negocio; se va "estrechando" porque no todos llegan al cierre. |
| **Tasa de cierre** | Negocios ganados ÷ (ganados + perdidos). |

**Preguntas probables del jurado:**

| Pregunta | Respuesta corta |
| --- | --- |
| ¿Por qué inbound? | La inmobiliaria ya tiene un portal que atrae clientes; lo lógico es convertir a esos interesados en lugar de buscar en frío. |
| ¿Por qué esas 7 etapas? | Reflejan el proceso real de una venta inmobiliaria: interés, visita, oferta, trámites y cierre. |
| ¿Qué diferencia hay entre lead y negocio? | El lead es el interés inicial; el negocio es la oportunidad que el vendedor trabaja por etapas hasta cerrar. |
| ¿Cómo evitan que un cliente se pierda? | Siempre tiene un responsable, las tareas vencidas se marcan solas y todo queda en el historial. |
| ¿Cómo mide la gerencia los resultados? | Con el módulo de Estadísticas: consultas, visitas, cierres, monto por etapa y rendimiento por vendedor. |
