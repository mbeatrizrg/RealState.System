Módulo · Negocios

Cada venta o alquiler, por etapas

  • Vista de tabla y de tablero (pipeline)
  • Se arrastra la tarjeta para cambiar de etapa
  • Monto acumulado por etapa
  • Filtros, columnas y exportación Excel / PDF
Un negocio es una oportunidad concreta: un cliente interesado en un inmueble, para venta o alquiler. Se ve como tabla, con filtros por propietario, etapa, operación, tipo de inmueble y fechas, o como tablero, donde cada etapa es una columna y el vendedor arrastra la tarjeta cuando el negocio avanza. Abajo de cada columna aparece el monto acumulado. Todo se puede exportar a Excel o PDF.
