Módulo · Tareas

Nada se olvida

  • Llamada, visita, envío, reunión o trámite
  • Prioridad y fecha de vencimiento
  • Las vencidas se marcan solas
  • Al completarla, el resultado queda como nota del cliente
Las tareas son los compromisos concretos del vendedor: llamar a un cliente, mostrar un inmueble, enviar opciones o pedir documentos. Cada una tiene tipo, prioridad, fecha de vencimiento y está vinculada a un contacto, un inmueble o un negocio. Si se pasa la fecha, el sistema la marca como vencida. Cuando el vendedor la completa, escribe el resultado y queda como nota en el historial del cliente.
