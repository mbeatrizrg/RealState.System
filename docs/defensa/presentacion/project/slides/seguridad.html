Seguridad y calidad desde el diseño

Acceso por roles

Administrador, vendedor y cliente del portal. El servidor vuelve a validar cada petición.

Cuentas protegidas

Claves cifradas con BCrypt, verificación por código al correo y cierre de sesión que invalida el token.

Base de datos versionada

7 migraciones SQL repetibles; el servidor avisa al arrancar si falta alguna.

Pruebas automáticas

93 pruebas entre backend y frontend verifican reglas, filtros, exportaciones y permisos.

La seguridad no se agregó al final. Cada pantalla y cada endpoint verifica el rol: un vendedor no puede modificar negocios de otro, y un cliente nunca ve el CRM. Las contraseñas se guardan cifradas, los clientes confirman su correo con un código y al cerrar sesión el token deja de servir. La base de datos se modifica solo con migraciones versionadas. Y hay 93 pruebas automáticas que comprueban que todo esto sigue funcionando.
