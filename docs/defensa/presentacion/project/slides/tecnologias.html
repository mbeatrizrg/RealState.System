Cada tecnología tiene un propósito concreto. Vue con TypeScript para una interfaz rápida y con menos errores. Spring Boot porque es el estándar en Java para APIs empresariales. PostgreSQL por ser una base relacional robusta; la usamos en Supabase para no administrar servidores. Spring Security con JWT y BCrypt para la seguridad. Apache POI y OpenPDF generan los Excel y PDF. Y tenemos pruebas automáticas en las dos capas: 58 en el backend, que corren las consultas reales sobre una base en memoria, y 35 en el frontend.
