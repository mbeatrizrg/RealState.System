02 · Tecnologías

Arquitectura en tres capas

Frontend

Portal público y CRM en el navegador.

Vue 3 · TypeScript · Vite

API REST

Reglas de negocio, seguridad y reportes.

Spring Boot 4 · Java 17

Base de datos

Una sola fuente de verdad para portal y CRM.

PostgreSQL en Supabase

Correo SMTP: códigos de verificación y correos a clientes

Archivos: fotos públicas y documentos privados

JWT: sesión segura entre navegador y API

El sistema está separado en tres capas. El frontend, hecho en Vue 3 con TypeScript, es lo que ven el cliente y el vendedor. El frontend habla con una API REST hecha en Spring Boot con Java 17, que contiene todas las reglas de negocio y la seguridad. Y todo se guarda en PostgreSQL, alojado en Supabase. Alrededor hay tres servicios de apoyo: el correo para enviar códigos y mensajes, el almacenamiento de fotos y documentos, y los tokens JWT que mantienen la sesión.
